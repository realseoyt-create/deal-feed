텔레그램 알림 안내

텔레그램을 한 번도 안 써봤어도 괜찮아요. 순서대로 따라 하면 5분이면 끝나요.

봇을 만들 필요 없어요. 이미 만들어진 @Pompoobot에 "시작"만 누르면 진짜 싼 딜이 올라올 때 알림이 와요.

  1. 텔레그램 앱 설치

    카카오톡 같은 무료 메신저예요. 폰에 설치하세요.

    iPhone (App Store) ▶ Android (Play 스토어) 💻 PC용

  2. 전화번호로 가입

    앱을 열고 Start Messaging(메시지 시작) → 국가 South Korea(+82) 선택 → 전화번호 입력 → 문자로 온 인증번호 5자리 입력 → 이름 입력하면 끝.

    💡 전화번호는 다른 사람에게 보이지 않아요. 봇도 내 번호를 알 수 없어요.

  3. 꿀딜 봇 열기

    폰에서 이 페이지를 보고 있다면 아래 버튼을 누르세요. 텔레그램 앱이 열려요.

    📲 @Pompoobot 열기
    PC에서 보고 있다면 폰 카메라로 이 QR을 찍으세요. 또는 텔레그램 검색창에 Pompoobot 을 입력해도 돼요.

  4. "시작" 누르기

    채팅방 맨 아래 시작(START) 버튼을 누르면 구독 완료! 환영 메시지가 오면 성공이에요.

    PPbot
    👋 꿀딜 알림 구독 완료! 시작 (START)
    💡 환영 메시지는 최대 10~20분 뒤에 와요. (봇이 10분마다 확인하기 때문이에요) 바로 안 와도 기다려 주세요.

  5. 알림 켜두기

    폰 설정에서 텔레그램 알림 허용이 켜져 있는지 확인하세요. 밤 11시~아침 7시 딜은 모아서 아침에 한 번에 와요.

이런 알림이 와요 (예시)

PPbot
🏆 AI 강력추천 — 다나와보다 35% 싸고 뽐뿌 역대 최저
[G마켓] 와이 액체세제 2.5L x 4개 · 6,810원
다나와 10,480원 대비 35% 쌈
💡 쿠폰 받기 · 토스페이 추가할인
뽐뿌 글 보기 · 다나와 보기

자주 묻는 질문

그만 받고 싶어요

봇 채팅방에 /stop 을 보내면 바로 해지돼요. 다시 받으려면 /start.

돈이 드나요? 내 정보가 보이나요?

무료예요. 봇은 내 전화번호를 알 수 없고, 알림을 보내기 위한 채팅 번호만 암호화해서 보관해요.

내가 원하는 상품만 받을 수 있나요?

네! 봇에게 /watch 기저귀 를 보내면 제목에 '기저귀'가 있는 딜을, /target 생수 10000 을 보내면 생수가 1만원 이하로 뜰 때 나에게만 알려줘요. 자세한 건 ⚙️ 봇 명령어 탭.

폰 홈 화면에 앱처럼 추가할 수 있나요?

네. 꿀딜 피드 웹을 폰에서 열고 — 아이폰은 Safari 공유 버튼 → 홈 화면에 추가, 안드로이드는 Chrome 메뉴(⋮) → 홈 화면에 추가(또는 앱 설치).

"시작" 버튼이 안 보여요

이미 대화한 적이 있으면 버튼 대신 입력창이 보여요. 입력창에 /start 를 쳐서 보내면 돼요.

봇 채팅방 입력창에 아래 명령을 보내면 돼요. 앞에 /(슬래시)를 꼭 붙이세요.

누구나

/start알림 구독 시작
/stop알림 구독 해지
/watch 기저귀내 키워드 추가 — 제목에 있으면 나에게만 알림 (최대 20개)
/unwatch 기저귀내 키워드 삭제
/target 생수 10000🎯 목표가 — '생수'가 1만원 이하로 뜨면 알림 (1만도 가능)
/untarget 생수목표가 삭제
/cycle 휴지 60🔁 재구매 주기 — 60일마다 그동안 올라온 싼 딜과 함께 알림 (7~365일)
/bought 휴지샀어요 — 주기를 오늘부터 다시 시작 (/uncycle 휴지로 삭제)
/mylist내 키워드·목표가·재구매 주기 보기
💡 일요일 저녁 8시에는 "이번 주 역대급 딜 TOP 5"가 와요.

관리자(봇 주인)만

/watch 생수관심 키워드 추가 — 제목에 들어 있으면 알림
/unwatch 생수키워드 삭제
/cat 식품관심 카테고리 켜기/끄기 (/cat만 보내면 목록)
/maxprice 30000관심 카테고리 최대 가격
/min 15다나와보다 몇 % 이상 싸야 알릴지
/exclude 중고제외어 추가 (/include로 삭제)
/quiet 23 7방해 금지 시간 (/quiet off로 끄기)
/list현재 설정 보기
/status수집 상태 확인
/subs구독자 수
💡 명령은 다음 수집 때(최대 10~20분) 반영되고, 그때 답장이 와요. 웹 화면의 "알림 조건 · 웹에서 바꾸기"에서도 바꿀 수 있어요.
이 서비스를 나만의 봇·나만의 조건으로 따로 운영하고 싶을 때만 필요해요. 알림만 받을 거라면 첫 번째 탭으로 충분해요.

  1. BotFather 열기

    텔레그램 공식 "봇 만드는 봇"이에요. 이름 옆에 파란 체크(✔)가 있는지 꼭 확인하세요.

    🤖 @BotFather 열기

  2. 새 봇 만들기

    입력창에 /newbot 을 보내고, 질문에 차례로 답하세요.

    BotFather ✔
    /newbot Alright, a new bot. How are we going to call it? 내 꿀딜봇 Now let's choose a username… It must end in `bot`. mydeal_alert_bot

    ① 표시 이름: 아무거나 (예: 내 꿀딜봇)
    ② 아이디: 영문으로, 끝이 bot으로 끝나야 해요 (예: mydeal_alert_bot). 이미 있으면 다른 걸로.

  3. 토큰 복사하기

    완료되면 "Use this token to access the HTTP API:" 아래에 1234567890:AAE... 같은 긴 글자가 와요. 이게 봇 토큰이에요. 길게 눌러 복사하세요.

    ⚠️ 토큰은 비밀번호예요. 다른 사람에게 보여주거나 공개된 곳에 붙이지 마세요. 노출됐으면 BotFather에 /revoke 로 새로 발급받으세요.

  4. 내 봇에게 말 걸기

    BotFather 메시지의 t.me/내봇아이디 링크를 눌러 내 봇을 열고 시작을 누르세요. (봇은 내가 먼저 말을 걸어야 메시지를 보낼 수 있어요)

  5. 내 채팅 ID 알아내기

    브라우저 주소창에 아래 주소를 넣으세요. 토큰 자리에 3단계 토큰을 붙여넣어요.

    https://api.telegram.org/bot토큰/getUpdates

    나오는 글자 중 "chat":{"id":123456789 의 숫자가 채팅 ID예요.

    💡 "result":[] 처럼 비어 있으면 4단계에서 봇에게 아무 말이나 한 번 더 보내고 새로고침하세요.

  6. 서비스에 연결하기

    이 서비스(GitHub 저장소)를 내 계정으로 복사(Fork)한 뒤, 저장소 Settings → Secrets and variables → Actions → New repository secret 에 아래 두 개를 등록하세요.

    TELEGRAM_BOT_TOKEN3단계의 봇 토큰
    TELEGRAM_CHAT_ID5단계의 채팅 ID 숫자
    GEMINI_API_KEY(선택) AI 판정용 — Google AI Studio에서 무료 발급

    그다음 Actions 탭에서 워크플로를 켜면 10분마다 자동으로 돌아가요. 이제 내 봇에서 /watch, /cat 등으로 나만의 조건을 설정할 수 있어요.
